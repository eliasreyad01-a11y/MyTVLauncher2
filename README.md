# Glass TV Launcher (MyTVLauncher2)

لانشر خاص لأجهزة Android TV / Google TV. كود جديد مكتوب من الصفر بـ Kotlin، بدون مكتبات خارجية غير androidx. الشكل مبني على صور الواجهة المنشورة للانشر المرجعي (التخطيط والقوائم فقط)، بدون أي من خلفياته أو خطوطه أو شعاراته.

## الميزات

**الشاشة الرئيسية**
- تحية حسب الوقت، ساعة كبيرة، والتاريخ.
- أزرار علوية: Wi-Fi (يفتح إعدادات الواي فاي)، بحث، والإعدادات.
- **صف المفضلة (Dock)** داخل شريط داكن بالبلاطات العريضة، وتحته شبكة كل التطبيقات. بلاطات التطبيقات بتستخدم صورة البانر الخاصة بكل تطبيق تلفاز إذا موجودة، وإلا أيقونة مع الاسم.
- اسم التطبيق المحدد بيظهر بخط كبير فوق الصف.
- **قائمة الإعدادات المنسدلة**: إعدادات الواجهة الرئيسية، بطاقات الصفحة الرئيسية، تعديل المفضلة، إعادة ترتيب التطبيقات، البحث عن التطبيقات، التطبيقات المخفية، حول التطبيق · الدعم، إعدادات نظام التلفاز.
- **ضغط OK مطولاً على تطبيق**: فتح، إضافة/إزالة من المفضلة، **نقل التطبيق**، معلومات التطبيق، إخفاء، إلغاء التثبيت.
- **نقل التطبيق**: حرّك بالأسهم، OK للحفظ، Back للإلغاء.
- **بطاقة أوقات الصلاة** على الصفحة الرئيسية (قابلة للإخفاء من "بطاقات الصفحة الرئيسية").

**الأذان**
- أذان تلقائي مع اختيار الصلوات، بحث عن المدينة، طريقة الحساب (الافتراضي عمّان + الأردن)، تجربة الأذان، وإيقافه من الإشعار.
- يعيد جدولة نفسه بعد إعادة التشغيل.

**Wallpaper Studio**
- 4 خلفيات جاهزة (Ocean Blue وAurora وDusk وMidnight، رسوماتها خاصة بهذا المشروع).
- صورة أو فيديو (يتكرر وبدون صوت).
- **عرض شرائح** للصور الشخصية: إضافة صورة من الذاكرة، حذف صورة، ومنع تكرار نفس الصورة. التبديل كل 30 ثانية.
- تحكم بتعتيم الخلفية.

**اللغة**: عربي وإنجليزي (من الإعدادات أو لغة النظام).

## اللي مش موجود (مقارنة بالمرجع)
- ويدجت الطقس (المرجع نفسه معطّله).
- اختصارات مداخل HDMI لتلفزيونات Xiaomi.
- 19 لغة (هنا لغتين فقط).
- صفحة الدعم بأكواد QR (هنا صفحة حول بسيطة).
- خط Outfit، والخلفيات الفنية الأصلية.

## البناء (على ويندوز)
1. ثبّت **Android Studio** (آخر إصدار).
2. File ← Open ← اختار مجلد `MyTVLauncher`. اتركه يعمل Sync (بنزّل Gradle والمكتبات لحاله).
3. **Build ← Build Bundle(s) / APK(s) ← Build APK(s)**.
4. الملف بيطلع هون: `app/build/outputs/apk/debug/app-debug.apk`

## التثبيت على التلفاز
```
adb connect IP_التلفاز:5555
adb install -r app-debug.apk
```
أو انسخ الـ APK على فلاشة وثبّته من مدير ملفات.

### تعيينه كشاشة رئيسية
بعض الأجهزة بتسألك أي لانشر تستخدم أول ما تضغط Home. إذا ما سألك، جرّب:
```
adb shell cmd package set-home-activity com.mytv.launcher/.MainActivity
```
(بعض التلفزيونات بتفرض اللانشر الرسمي.) خلّي اللانشر الأصلي شغّال ومش معطّل لحد ما تتأكد إن كل شي ثابت.

## الأذان والخلفيات: الملفات
ما في ملف أذان مرفق (لأسباب حقوق). عندك 3 خيارات:
1. الإعدادات ← صوت الأذان ← اختيار من الذاكرة.
2. انسخ الملف إلى `Android/data/com.mytv.launcher/files/Adhan/` واختاره من "مجلد التطبيق" (للتلفزيونات اللي ما فيها مدير ملفات).
3. ضع ملفاً اسمه `adhan.mp3` داخل `app/src/main/res/raw/` قبل البناء، فيصير الافتراضي.

نفس الفكرة: مجلد `Wallpapers` للخلفيات و`Slideshow` لصور عرض الشرائح.

استخدم ملفات صوت وصور إنت مرخّص تستخدمها.
